Windows to model: Claude/Codex `session`=5h (300 min) and `weekly`=7d (10080 min). Reset times: convert epoch seconds -> ISO UTC. A window whose reset time has passed is no longer current.
Expiry (suggested): live readings valid 15 min (statusline: until its resets_at too), manual 24 h; expired => STALE with values retained as history, never VERIFIED.
Cross-account contamination is the key risk: keep one file per alias; reject a reading whose alias does not match the collector that produced it.
